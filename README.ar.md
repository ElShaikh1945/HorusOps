## 🌟 نظرة عامة

مشروع **WAISoft-Reports** هو نظام شامل ومفتوح المصدر مصمم لإدارة ومتابعة بيئة التطوير الخاصة بك تلقائيًا وبأمان كامل محليًا بدون أي خوادم وسيطة (Zero Telemetry):
1. **أتمتة مستودعات Git**: فحص التعديلات، عمل Commit ذكي بالذكاء الاصطناعي، ورفع التعديلات للـ GitHub دوريًا.
2. **إدارة الخوادم والعمليات**: تشغيل ومتابعة خوادم التطوير (Next.js, Vite, Python, Django, Express...) مع مراقبة المنافذ وحفظ المعرّفات وإعادة التشغيل عند التعطل.
3. **محرك البناء والنشر CI/CD**: تشغيل عمليات بناء التطبيقات (Flutter, Docker, PyPI...) وتلقي تقارير مفصلة بالنتائج.
4. **مركز تحكم تيليجرام ذكي**: بوت متقدم يحتوي على 14 أمرًا مباشرًا (بدون شرطات سفلية `_`)، لوحات أزرار تفاعلية، دعم للرسائل الصوتية وتحليل الأخطاء عبر نموذج Groq Llama 3.3.
5. **معالج إعداد عبر الويب (`setup_wizard.py`)**: واجهة ويب خفيفة وسريعة (Tailwind CSS) بدون أي مكتبات خارجية إضافية، تتيح اختبار الاتصال بتيليجرام و Groq و GitHub وحفظ الإعدادات بنقرة واحدة.

## 🚀 البدء السريع

### 1. استنساخ المستودع
```bash
git clone https://github.com/your-username/WAISoft-Reports.git
cd WAISoft-Reports
```

### 2. تشغيل معالج الإعداد (Web Setup Wizard)
```bash
./scripts/setup.sh
```
أو عبر بايثون مباشرة:
```bash
python3 setup_wizard.py --port 8585
```
افتح المتصفح على: **`http://localhost:8585`**
1. أدخل **توكن بوت تيليجرام** و **معرف الشات** واضغط **Test Telegram**.
2. أدخل **مفتاح Groq API** واضغط **Test Groq**.
3. أدخل مسارات مشاريعك وخوادمك ومستهدفات البناء.
4. اضغط **Save Settings**.

## 🏃 تشغيل الخدمات

### تشغيل البوت مباشرة
```bash
pip install -r requirements.txt
./scripts/run_bot.sh
```

### تشغيل مزامنة Git يدويًا
```bash
./scripts/run_sync.sh
```

### التثبيت كخدمة تعمل في الخلفية تلقائيًا مع إقلاع النظام

#### على نظام ماك (macOS launchd):
```bash
./scripts/install_launchd.sh
```
- سجلات العمل: `server_logs/bot_stdout.log`
- إيقاف الخدمة: `launchctl stop com.waisoft.bot`

#### على أنظمة لينكس (Linux systemd):
```bash
./scripts/install_systemd.sh
```
- حالة الخدمة: `systemctl --user status waisoft-bot.service`
- سجلات العمل: `journalctl --user -u waisoft-bot.service -f`

## 🤖 أوامر بوت تيليجرام (بدون شرطة سفلية)

| الأمر | الوصف | مثال |
| :--- | :--- | :--- |
| `/status` | تقرير فوري شامل عن حالة النظام (المعالج، الرام، الأقراص، الخوادم النشطة) | `/status` |
| `/managerreport` | تقرير إداري تفصيلي شامل لأداء المشاريع والخوادم والتنبيهات | `/managerreport` |
| `/diagnose [target]` | تشخيص ذكي للأخطاء وسجلات الخوادم باستخدام الذكاء الاصطناعي Groq | `/diagnose api` |
| `/servers` | عرض قائمة بجميع الخوادم المهيأة مع لوحة تحكم تفاعلية | `/servers` |
| `/server <name>` | تفاصيل وحالة خادم محدد ومراقبة المنفذ | `/server web` |
| `/startserver <name>` | تشغيل خادم محدد من القائمة | `/startserver web` |
| `/stopserver <name>` | إيقاف خادم يعمل في الخلفية | `/stopserver web` |
| `/restart <name>` | إعادة تشغيل خادم محدد | `/restart web` |
| `/build <target>` | تشغيل خط أنابيب بناء CI/CD محدد | `/build mobile` |
| `/sync` | بدء دورة مزامنة فورية لجميع مستودعات Git | `/sync` |
| `/repos` | استعراض جميع المستودعات وحالتها المحلية مقارنة بالسحابة | `/repos` |
| `/report` | ملخص سريع لعمليات اليوم في مستودعات Git | `/report` |
| `/clearcache` | تنظيف الذاكرة المؤقتة وسجلات الأخطاء القديمة | `/clearcache` |
| `/help` | دليل الأوامر وطريقة الاستخدام | `/help` |

> 💡 **الأوامر الصوتية**: يمكنك إرسال رسالة صوتية للبوت وسيقوم الذكاء الاصطناعي بتفريغها صوتيًا وتنفيذ الأمر المطلوب بدقة!

## 🔒 الأمان والخصوصية

- **عزل كامل للبيانات الحساسة**: جميع التوكنات والمفاتيح محفوظة بملف `.env` المستثنى تمامًا في `.gitignore`.
- **تنفيذ محلي 100%**: البرنامج لا يتصل بأي خوادم تتبع أو خدمات خارجية باستثناء واجهات الـ API الرسمية لتيليجرام و Groq و GitHub التي تقوم بتهيئتها بنفسك.
- **حماية بالمعرّف**: حصر الأوامر الحساسة على المعرّفات المحددة في `TELEGRAM_ADMIN_IDS`.
